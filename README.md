# สมุดบัญชีออมทรัพย์ (Savings Passbook)

เครื่องมือออมเงินตามแผน ในรูปแบบสมุดบัญชีธนาคาร — ตั้งเป้าหมาย ระบบคำนวณตารางงวดให้อัตโนมัติ บันทึกยอดที่ออมจริงได้หลายรายการต่องวด พร้อมกราฟและตารางสรุปภาพรวม

ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้างไฟล์

```
savings-passbook/
├── index.html   หน้าเว็บหลัก / โครงสร้าง UI
├── style.css    ธีมและสไตล์ทั้งหมด
├── script.js    ตรรกะการทำงาน (คำนวณ, บันทึกข้อมูล, กราฟ)
└── README.md    ไฟล์นี้
```

**ต้องเก็บทั้ง 3 ไฟล์ไว้ในโฟลเดอร์เดียวกัน** แล้วเปิด `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย) — ถ้าแยกไฟล์ออกจากกันหรือเปลี่ยนชื่อไฟล์ หน้าเว็บจะโหลด CSS/JS ไม่สำเร็จ

## วิธีใช้งาน

1. **ตั้งเป้าหมายการออม** — กรอกชื่อเป้าหมาย ยอดเงินเป้าหมาย วันที่เริ่ม/สิ้นสุด ความถี่ (รายเดือน/รายสัปดาห์) และ % เงินเดือนที่แนะนำ (ค่าเริ่มต้น 10%)
2. ระบบจะสร้าง **สมุดรายการ** แบ่งเป็นงวดให้อัตโนมัติ พร้อมยอดที่ควรออม/งวด
3. กดวงกลม (○/✓) ที่แต่ละงวดเพื่อเปิดหน้าบันทึก:
   - กรอกเงินเดือนของงวดนั้น → ระบบคำนวณ % ให้ดูเป็นข้อมูลอ้างอิง
   - เพิ่มรายการที่ออมจริงได้หลายรายการในงวดเดียวกัน (วันที่ + จำนวนเงิน) — ยอดรวมของงวดจะถูกคำนวณจากทุกรายการ
   - ลบรายการที่บันทึกผิดได้ด้วยปุ่ม ✕
4. ดูความคืบหน้าได้จาก:
   - แถบ progress bar และสถานะ "ตามแผน / ช้ากว่าแผน / ครบเป้าหมายแล้ว"
   - ตาราง **ภาพรวมทุกงวด** เทียบแผนกับยอดจริงแต่ละงวด
   - **กราฟแท่ง** เปรียบเทียบแผนกับยอดออมจริงรายงวด
5. **จัดการข้อมูล**:
   - **ส่งออกเป็นไฟล์ (JSON)** — ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์สำรอง
   - **นำเข้าไฟล์** — โหลดไฟล์ JSON ที่เคยส่งออกไว้กลับเข้ามา (จะแทนที่ข้อมูลปัจจุบันทั้งหมด)
   - **ล้างข้อมูลทั้งหมด** — รีเซ็ตแผนและประวัติการออมทั้งหมด (ย้อนกลับไม่ได้)

## การเก็บข้อมูล

ข้อมูลถูกเก็บอัตโนมัติใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ ภายใต้คีย์ `savingsPassbookData_v2`

ข้อจำกัด:
- ข้อมูลผูกกับเบราว์เซอร์/เครื่องที่ใช้เปิดไฟล์ ถ้าเปลี่ยนเบราว์เซอร์หรือเครื่อง ต้อง export/import ไฟล์ JSON เพื่อย้ายข้อมูล
- การล้างแคช/ประวัติเบราว์เซอร์อาจทำให้ข้อมูลหายได้ ควร export เก็บไว้เป็นระยะ

## รูปแบบข้อมูล (JSON)

```json
{
  "goal": {
    "name": "กองทุนฉุกเฉิน",
    "target": 60000,
    "start": "2026-01-01",
    "end": "2026-12-31",
    "freq": "monthly",
    "percent": 10
  },
  "entries": {
    "1": {
      "salary": 30000,
      "records": [
        { "date": "2026-01-05", "amount": 3000 }
      ]
    }
  }
}
```

- `entries` เก็บตามลำดับงวด (key = หมายเลขงวด เริ่มที่ 1)
- `salary` ใช้เป็นข้อมูลอ้างอิงคำนวณ % เท่านั้น ไม่ผูกกับยอดที่ออมจริง
- `records` คือรายการฝากจริงทั้งหมดในงวดนั้น ยอดรวมของงวด = ผลรวม `amount` ในนี้

## เทคโนโลยีที่ใช้

- HTML / CSS / Vanilla JavaScript (ไม่มี framework)
- [Chart.js](https://www.chartjs.org/) (โหลดผ่าน CDN) สำหรับกราฟเปรียบเทียบ
- ฟอนต์ Sarabun และ JetBrains Mono จาก Google Fonts

## ความเข้ากันได้

ต้องใช้เบราว์เซอร์ที่รองรับ ES6+ และ `localStorage` (Chrome, Edge, Firefox, Safari รุ่นใหม่ทั้งหมดใช้ได้) หากเปิดผ่าน `file://` โดยตรง ฟีเจอร์ export/import และการโหลดฟอนต์/Chart.js จาก CDN ต้องมีอินเทอร์เน็ตเชื่อมต่ออยู่ (เฉพาะฟอนต์และกราฟ ส่วนตัวแอปหลักทำงานออฟไลน์ได้)
