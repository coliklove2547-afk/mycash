# สมุดบัญชีออมทรัพย์ (Savings Passbook)

เครื่องมือออมเงินในรูปแบบสมุดบัญชีธนาคาร — **เป้าหมายการออมไม่ใช่ยอดตายตัว แต่เป็นผลรวมสะสมของ % เงินเดือนที่กรอกไว้ในแต่ละเดือน** เช่น 10% ของเงินเดือนธันวา (1,500) รวมกับ 10% ของเงินเดือนมกรา (500) เท่ากับเป้าหมายสะสม 2,000 บาท เพิ่มเดือนใหม่ได้เรื่อย ๆ ไม่จำกัดวันสิ้นสุด บันทึกยอดที่ออมจริงได้หลายรายการต่อเดือน พร้อมกราฟและตารางสรุปภาพรวม

ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้างไฟล์

```
savings-passbook/
├── index.html      หน้าเว็บหลัก / โครงสร้าง UI
├── style.css       ธีมและสไตล์ทั้งหมด
├── script.js       ตรรกะการทำงาน (คำนวณ, บันทึกข้อมูล, กราฟ, ป๊อบอัพ)
├── manifest.json   ข้อมูลสำหรับติดตั้งเป็นแอป
├── sw.js           Service Worker สำหรับใช้งานออฟไลน์
├── favicon.ico     ไอคอนแท็บเบราว์เซอร์
├── icons/          ไอคอนแอปทุกขนาด
└── README.md       ไฟล์นี้
```

**ต้องเก็บไฟล์และโฟลเดอร์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน** แล้วเปิด `index.html` ด้วยเบราว์เซอร์ — ถ้าแยกไฟล์ออกจากกันหรือเปลี่ยนชื่อไฟล์ หน้าเว็บจะโหลด CSS/JS/ไอคอนไม่สำเร็จ

## วิธีใช้งาน

แอปแบ่งเป็น 3 หน้า สลับได้จากเมนูแท็บใต้หัวสมุด:

- **🏠 หน้าหลัก** — เลือกเดือน/ปี, กรอกเงินเดือน, บันทึกรายการออมจริงของเดือนนั้น, สรุปความคืบหน้าสะสม และสมุดรายการรายเดือนทั้งหมด (มีปุ่ม "⚙️ การตั้งค่า" ลัดไปหน้าตั้งค่าได้จากตรงนี้)
- **📋 สรุป** — ตารางภาพรวมทุกเดือน และกราฟเปรียบเทียบเป้าหมายกับยอดออมจริง
- **⚙️ ตั้งค่า** — ตั้งชื่อสมุด, % เป้าหมาย, และเครื่องมือจัดการข้อมูล (export/import/รีเฟรช/ล้างข้อมูล)

ขั้นตอนหลัก:

1. ไปหน้า **ตั้งค่า** ก่อน — ตั้งชื่อสมุด (ไม่บังคับ) และ % เงินเดือนที่ใช้คำนวณเป้าหมายในแต่ละเดือน (ค่าเริ่มต้น 10%)
2. กลับมาหน้า **หลัก** — เลือกเดือน/ปี กรอก **เงินเดือนของเดือนนั้น** → ระบบคำนวณเป้าหมายของเดือนนั้น (เงินเดือน × %) ให้ดูทันที แล้วกด "บันทึกเงินเดือนเดือนนี้"
3. เพิ่มรายการที่ออมจริงได้หลายรายการต่อเดือน (วันที่ + จำนวนเงิน) ในการ์ดถัดมา ยอดรวมของเดือนจะคำนวณจากทุกรายการที่เพิ่มเข้ามา ลบรายการที่บันทึกผิดได้ด้วยปุ่ม ✕
4. เพิ่มเดือนใหม่ได้เรื่อย ๆ ไม่จำกัดจำนวน — **เป้าหมายสะสมทั้งหมด = ผลรวมของ (เงินเดือน × %) ของทุกเดือนที่กรอกไว้** เดือนที่ยังไม่กรอกเงินเดือนจะไม่ถูกนับเข้าเป้าหมาย
5. ในหน้าหลักเดียวกันนี้ยังมี progress bar, สถานะเทียบยอดออมสะสมกับเป้าหมาย, และสมุดรายการรายเดือน (กดไอคอนดินสอ ✎ ที่แถวไหนเพื่อย้อนกลับไปแก้เดือนนั้น)
6. ไปหน้า **สรุป** เพื่อดูตารางภาพรวมทุกเดือนและกราฟแท่งเปรียบเทียบ
7. ในหน้า **ตั้งค่า**:
   - **ส่งออก JSON / CSV / Excel (.xlsx)** — ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์สำรอง เลือกฟอร์แมตได้ตามสะดวก
   - **นำเข้าไฟล์** — รองรับทั้ง `.json`, `.csv`, `.xlsx` ที่เคยส่งออกจากแอปนี้ (จะแทนที่ข้อมูลปัจจุบันทั้งหมด)
   - **🔄 รีเฟรชข้อมูล** — โหลดข้อมูลล่าสุดจาก localStorage ขึ้นมาใหม่ (มีประโยชน์เวลาเปิดหลายแท็บ)
   - **ล้างข้อมูลทั้งหมด** — รีเซ็ตการตั้งค่าและประวัติการออมทุกเดือน (ย้อนกลับไม่ได้)

> **หมายเหตุ:** % ที่ตั้งไว้เป็นค่ากลางใช้กับทุกเดือน หากแก้ไข % ภายหลัง เป้าหมายของเดือนที่มีเงินเดือนอยู่แล้วจะถูกคำนวณใหม่ตาม % ล่าสุดทันที (ยอดเงินเดือนที่กรอกไว้จะไม่หาย แต่ตัวเลขเป้าหมายจะเปลี่ยนตาม %)

## ติดตั้งเป็นแอป (เหมือน Facebook, LINE, YouTube, TikTok)

แอปนี้รองรับการ "ติดตั้ง" ลงหน้าจอโฮมของมือถือ/คอมพิวเตอร์ได้ มีโลโก้ของตัวเองแยกจากเบราว์เซอร์ เปิดแล้วเต็มจอไม่มีแถบที่อยู่ (URL bar) เหมือนแอปทั่วไป — ไฟล์ที่เพิ่มมาเพื่อการนี้:

```
savings-passbook/
├── favicon.ico          ไอคอนที่แท็บเบราว์เซอร์
├── manifest.json         ข้อมูลแอป (ชื่อ, ไอคอน, สีธีม) สำหรับติดตั้ง
├── sw.js                 Service Worker (แคชไฟล์ไว้ใช้งานออฟไลน์)
└── icons/                ไอคอนแอปทุกขนาด (16px–512px)
```

> **⚠️ ข้อจำกัดสำคัญ:** การติดตั้งเป็นแอป (ปุ่ม "ติดตั้ง" / "Add to Home Screen") **ใช้ไม่ได้ถ้าเปิดไฟล์แบบดับเบิลคลิกตรงๆ** (`file://...`) เบราว์เซอร์ทุกยี่ห้อบล็อกฟีเจอร์นี้บนโปรโตคอล `file://` ด้วยเหตุผลด้านความปลอดภัย ต้องเปิดผ่าน **เว็บเซิร์ฟเวอร์** เท่านั้น (ไม่ว่าจะจริงหรือทดสอบในเครื่อง) ตัวแอปเองยังใช้งานได้ปกติทุกฟีเจอร์ถ้าเปิดแบบ `file://` เพียงแต่จะไม่มีปุ่มติดตั้งขึ้นมาให้

**วิธีเปิดผ่านเว็บเซิร์ฟเวอร์เพื่อให้ติดตั้งได้:**

- **ทดสอบในเครื่องตัวเอง:** เปิด terminal ในโฟลเดอร์นี้แล้วรัน `python3 -m http.server 8000` จากนั้นเข้า `http://localhost:8000` ผ่านเบราว์เซอร์
- **ใช้งานจริงข้ามอุปกรณ์:** อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสติ้งฟรีที่รองรับ HTTPS เช่น GitHub Pages, Netlify, Vercel หรือ Cloudflare Pages แล้วเข้าผ่านลิงก์ที่ได้
- เมื่อเข้าผ่าน `http://localhost` หรือ `https://` แล้ว เบราว์เซอร์ (Chrome/Edge บน Android, Safari บน iOS ใช้ "แชร์ > เพิ่มไปยังหน้าจอโฮม") จะขึ้นตัวเลือกให้ติดตั้งเป็นแอปได้เอง

## การเก็บข้อมูล

ข้อมูลถูกเก็บอัตโนมัติใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ ภายใต้คีย์ `savingsPassbookData_v3`

ข้อจำกัด:
- ข้อมูลผูกกับเบราว์เซอร์/เครื่องที่ใช้เปิดไฟล์ ถ้าเปลี่ยนเบราว์เซอร์หรือเครื่อง ต้อง export/import ไฟล์ JSON เพื่อย้ายข้อมูล
- การล้างแคช/ประวัติเบราว์เซอร์อาจทำให้ข้อมูลหายได้ ควร export เก็บไว้เป็นระยะ

## รูปแบบข้อมูล (JSON)

```json
{
  "settings": {
    "name": "กองทุนฉุกเฉิน",
    "percent": 10
  },
  "months": {
    "2025-12": {
      "salary": 15000,
      "records": [
        { "date": "2025-12-05", "amount": 1500 }
      ]
    },
    "2026-01": {
      "salary": 5000,
      "records": [
        { "date": "2026-01-05", "amount": 500 }
      ]
    }
  }
}
```

- `months` เก็บตามคีย์ `YYYY-MM` เพิ่มได้ไม่จำกัดจำนวนเดือน
- `salary` คือเงินเดือนที่กรอกไว้ของเดือนนั้น ใช้คำนวณเป้าหมายของเดือนนั้น = `salary × settings.percent / 100`
- `records` คือรายการฝากจริงทั้งหมดในเดือนนั้น ยอดรวมของเดือน = ผลรวม `amount` ในนี้
- **เป้าหมายสะสมทั้งหมด** = ผลรวมเป้าหมายของทุกเดือนที่มี `salary` (ตัวอย่างข้างบน = 1,500 + 500 = 2,000 บาท)

### รูปแบบไฟล์ CSV / Excel (.xlsx)

ไฟล์ CSV/XLSX ที่ส่งออกมีโครงสร้างแบบ **1 แถว = 1 รายการออม** เพื่อให้นำเข้ากลับมาใช้ต่อได้ครบถ้วน:

```
ชื่อสมุด,กองทุนฉุกเฉิน
เปอร์เซ็นต์,10

เดือน (YYYY-MM),เงินเดือน,วันที่ออม (YYYY-MM-DD),จำนวนเงิน
2025-12,15000,2025-12-05,1500
2026-01,5000,2026-01-05,500
```

- สองแถวแรกเก็บชื่อสมุดและ % ไว้สำหรับนำเข้ากลับ
- เงินเดือนของแต่ละเดือนจะอยู่ในแถวแรกของเดือนนั้นเท่านั้น (แถวถัดไปในเดือนเดียวกันเว้นว่างไว้) ถ้าเดือนไหนกรอกเงินเดือนแต่ยังไม่มีรายการออม จะมี 1 แถวที่มีเดือน+เงินเดือน แต่ไม่มีวันที่/จำนวนเงิน
- เปิดไฟล์ .xlsx ด้วย Excel/Google Sheets ได้โดยตรง เพื่อดูหรือแก้ไขก่อนนำเข้ากลับมาก็ได้ (ต้องคงชื่อหัวคอลัมน์และโครงสร้างแถวเดิมไว้ ไม่งั้นระบบจะนำเข้าไม่ได้)

## เทคโนโลยีที่ใช้

- HTML / CSS / Vanilla JavaScript (ไม่มี framework)
- [Chart.js](https://www.chartjs.org/) (โหลดผ่าน CDN) สำหรับกราฟเปรียบเทียบ
- [SheetJS (xlsx)](https://sheetjs.com/) (โหลดผ่าน CDN) สำหรับส่งออก/นำเข้าไฟล์ CSV และ Excel
- ฟอนต์ Sarabun และ JetBrains Mono จาก Google Fonts

## ความเข้ากันได้

ต้องใช้เบราว์เซอร์ที่รองรับ ES6+ และ `localStorage` (Chrome, Edge, Firefox, Safari รุ่นใหม่ทั้งหมดใช้ได้) หากเปิดผ่าน `file://` โดยตรง ฟีเจอร์ export/import และการโหลดฟอนต์/Chart.js จาก CDN ต้องมีอินเทอร์เน็ตเชื่อมต่ออยู่ (เฉพาะฟอนต์และกราฟ ส่วนตัวแอปหลักทำงานออฟไลน์ได้)
