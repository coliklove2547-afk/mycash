# Salary Tracker

สคริปต์สรุปเงินเดือน/ค่าใช้จ่ายจากไฟล์ Excel

## ติดตั้ง
```
pip install pandas openpyxl
```

## ใช้งาน
1. เตรียมไฟล์ Excel ที่มีคอลัมน์: `วันที่`, `ประเภท` (รายรับ/รายจ่าย), `หมวดหมู่`, `จำนวนเงิน`
2. รัน:
```
python summary.py data.xlsx
```
3. ผลลัพธ์จะแสดงในหน้าจอ และสร้างไฟล์ `summary.xlsx` (แยกตามหมวดหมู่ + รายเดือน)

## ไฟล์ตัวอย่าง
สร้างไฟล์ตัวอย่างด้วย:
```
python make_sample.py
```
