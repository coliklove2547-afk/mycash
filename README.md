## ✨ ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|--------|------------|
| **บันทึกรายรับ/รายจ่าย** | เพิ่มรายการพร้อมวันที่ ชื่อ จำนวน หมวดหมู่ บัญชี และหมายเหตุ |
| **กระเป๋าเงินหลายบัญชี** | สร้างบัญชีเงินสด/ธนาคาร ดูยอดคงเหลือ และโอนเงินระหว่างบัญชี |
| **ติดตามยืม-คืน** | สรุปยอดค้างชำระแยกตามบุคคล พร้อมกราฟความคืบหน้า |
| **สินเชื่อ & ผ่อนชำระ** | จัดการเงินกู้ ผ่อนมือถือ/PayNext บันทึกการจ่ายงวด |
| **หมวดหมู่** | เพิ่ม/ลบ/รีเซ็ตหมวดหมู่รายรับและรายจ่าย |
| **ลิสต์ทูเพย์ (Bills)** | รายการค้างจ่าย/ค้างรับ พร้อมตัวเลือกทำซ้ำทุกเดือน |
| **แดชบอร์ดสรุป** | กราฟแท่งและโดนัทสรุปรายเดือน แยกหมวดหมู่ |
| **ค้นหา** | ค้นหารายการจากชื่อ หมายเหตุ หรือหมวดหมู่ |
| **นำเข้า/ส่งออก** | ส่งออกเป็น XLSX และนำเข้าจากไฟล์ XLSX |
| **ข้อมูลสำรอง** | คัดลอกข้อมูลทั้งหมดเป็น JSON เพื่อแชร์หรือเก็บสำรอง |
| **Offline First** | ข้อมูลทั้งหมดเก็บใน `localStorage` ไม่ต้องเชื่อมต่ออินเทอร์เน็ต |

## 🖥️ ภาพรวมหน้าจอ

- **หน้าหลัก** – เพิ่มรายการ ดูรายการทั้งหมด กรองตามประเภท/บัญชี
- **กระเป๋าเงิน** – จัดการบัญชี โอนเงิน ดูสรุปยอด
- **ยืม-คืน** – ติดตามหนี้สินแยกรายบุคคล
- **สินเชื่อ** – จัดการผ่อนชำระ บันทึกการจ่ายงวด
- **หมวดหมู่** – ปรับแต่งหมวดหมู่รายรับ/รายจ่าย
- **สรุป** – แดชบอร์ดพร้อมกราฟรายเดือน
- **ลิสต์ทูเพย์** – รายการค้างจ่าย/ค้างรับ
- **ค้นหา** – ค้นหาและกรองรายการ
- **ตั้งค่า** – ดูสถิติและจัดการข้อมูล (ล้างข้อมูล, นำเข้า/ส่งออก)

---

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5 + CSS3** – ดีไซน์ responsive รองรับมือถือ
- **Vanilla JavaScript (ES6)** – โค้ดฝั่งไคลเอนต์ทั้งหมด
- **SheetJS (xlsx)** – สำหรับนำเข้า/ส่งออกไฟล์ Excel
- **Canvas API** – วาดกราฟแท่งและโดนัท
- **localStorage** – เก็บข้อมูลถาวรในเบราว์เซอร์

---

## 📦 วิธีติดตั้งและรัน

1. **ดาวน์โหลดไฟล์ทั้งหมด** – `index.html`, `style.css`, `script.js`
2. **เปิดไฟล์ `index.html` ในเบราว์เซอร์** (Chrome / Edge / Firefox / Safari)
3. **ไม่จำเป็นต้องใช้เซิร์ฟเวอร์** – ทำงานได้ทันที (ยกเว้นฟีเจอร์นำเข้า/ส่งออก XLSX ที่ต้องใช้ Internet เพื่อโหลดไลบรารีจาก CDN)

> 💡 **แนะนำ:** เปิดบนมือถือหรือใช้ Developer Tools ของเบราว์เซอร์ในโหมดอุปกรณ์เคลื่อนที่ เพื่อให้เห็น UI ที่ออกแบบมาสำหรับหน้าจอขนาดเล็ก

## 🧭 การใช้งานพื้นฐาน

### 1. เพิ่มรายการ
- เลือกวันที่, กรอกรายการ, จำนวนเงิน
- เลือกโหมด รายรับ/รายจ่าย
- เลือกหมวดหมู่และบัญชี
- กด **บันทึก**

### 2. จัดการกระเป๋าเงิน
- ไปที่หน้า **กระเป๋าเงิน**
- เพิ่มบัญชีใหม่พร้อมยอดเริ่มต้น
- ใช้ฟอร์ม **โอนเงินระหว่างบัญชี** เพื่อย้ายเงิน

### 3. ติดตามสินเชื่อ
- ไปที่หน้า **สินเชื่อ**
- เลือกแท็บ มือถือ หรือ PayNext
- เพิ่มรายการผ่อนด้วยยอดรวม งวดละ และจำนวนงวด
- กด **จ่ายงวด** เพื่อบันทึกการชำระ (รายการจะถูกบันทึกลงในหน้าหลักอัตโนมัติ)

### 4. ใช้ลิสต์ทูเพย์
- ไปที่หน้า **ลิสต์ทูเพย์**
- เพิ่มรายการค้างจ่าย/ค้างรับ พร้อมวันครบกำหนด
- เมื่อจ่ายแล้วให้กด **จ่ายแล้ว/รับแล้ว** เพื่อบันทึกรายการจริง

### 5. ค้นหาและกรอง
- ใช้ช่องค้นหาที่หน้า **ค้นหา** ค้นหาจากชื่อ/หมายเหตุ/หมวดหมู่
- กรองตามประเภทรายการและกระเป๋าเงิน
